## IPTV Player 1.0.0

Первый публичный релиз.

### Что внутри
- Portable `.exe` для Windows 10/11 (установка не нужна).
- Плейлисты m3u/m3u8, Xtream Codes, локальные файлы.
- HLS (hls.js) и «сырой» MPEG-TS/FLV (mpegts.js).
- Автоматическое перекодирование FFmpeg для HEVC/H.265, MPEG-2 и AC-3.
- XMLTV EPG: текущая и следующая передача.
- Поиск по всем плейлистам с подсветкой совпадений.
- Избранное, недавние, категории, виртуальный список каналов.
- Локальный прокси: CORS, User-Agent, Referer, Basic Auth, HLS-манифесты.

### Запуск
1. Скачайте `IPTV-Player-1.0.0-x64.exe`.
2. Запустите (SmartScreen → «Подробнее» → «Выполнить»).
3. «Плейлист» → добавьте ссылку, файл или Xtream-доступ.
